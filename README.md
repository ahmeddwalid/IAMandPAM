# IAM & PAM Reference

A Docusaurus v3 reference site covering Identity and Access Management and Privileged Access Management, built as a public portfolio piece and personal learning system.

Operating rules for AI agents: `AGENTS.md` (design law, diagram policy, content integrity) and `SPEC.md` (phase breakdown and checkpoints). Session status: `PROGRESS.md`.

```bash
npm install
npm run start   # local dev
npm run build   # production build with broken-link check
```
