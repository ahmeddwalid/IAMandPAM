# Code Samples Library

Ready-to-use code samples for common IAM and PAM tasks. Each sample includes what it does, prerequisites, the code, expected output, and common errors. Copy, adapt, and run.

## In this section

- **[PowerShell](powershell.md)** — AD user management, group management, GPO queries, and PAM session analysis
- **[Python](python.md)** — SCIM client, AWS IAM policy analyzer, Azure AD Graph API, and certificate validation
- **[Bash](bash.md)** — LDAP queries, Kerberos ticket inspection, certificate generation, and Vault CLI
- **[Terraform](terraform.md)** — AWS IAM roles, Azure AD app registrations, and GCP service accounts

## How to use this section

Each sample is self-contained: copy the code, install the prerequisites, and run. The samples are designed to be adapted to your environment, not used as-is in production. Always test in a lab environment first.

See the [site topic map](/) for where these samples fit in the overall learning path.
