# دليل السيرة الذاتية والمعرض لأدوار IAM

## ما يبحث عنه مديرو التوظيف فعليًا

مديرو التوظيف لأدوار IAM يفحصون السير الذاتية بحثًا عن إشارات محددة. لا يبحثون عن سيرة ذاتية أمنية عامة. يريدون رؤية:

- **تقنيات محددة**: Keycloak, Entra ID, CyberArk, SailPoint, Okta, AWS IAM, Azure RBAC. اذكر أسماء المنتجات الدقيقة التي عملت معها.
- **عمق البروتوكول**: SAML, OIDC, OAuth 2.0, SCIM, LDAP, Kerberos. ليس مجرد الألفة، بل خبرة التكامل.
- **أرقام الحجم**: كم عدد المستخدمين؟ كم عدد التطبيقات؟ كم عدد الحسابات المميزة؟ الأرقام تجعل الادعاءات موثوقة.
- **نتائج المشاريع**: ليس فقط ما فعلته، بل ما مكّنه. "خفض وقت الإعداد بنسبة 40%" أقوى من "نفّذت SSO."
- **أدلة استكشاف الأخطاء**: رسائل خطأ محددة، وأسباب جذرية، وحلول. هذا يثبت أنك شغّلت التقنية، لم تقرأ عنها فقط.

## هيكل السيرة الذاتية لأدوار IAM

### الرأس

الاسم، الموقع، البريد الإلكتروني، LinkedIn, GitHub. لا صورة، لا عمر، لا حالة اجتماعية.

### الملخص (2-3 أسطر)

بيان مركّز عما تفعله وما تبحث عنه. ليس بيان هدف.

```
مهندس IAM بخبرة 3 سنوات في هوية المؤسسات: Entra ID, Keycloak, اتحاد SAML/OIDC, وأساسيات PAM. أبحث عن دور مهندس IAM أول في بيئة سحابية أولاً.
```

### قسم المهارات

جمّع المهارات حسب الفئة. كن محددًا.

```
مزودو الهوية: Keycloak, Entra ID, Okta, Auth0
البروتوكولات: SAML 2.0, OIDC, OAuth 2.0, SCIM, LDAP, Kerberos
PAM: CyberArk (PVWA, PSM, CPM), Delinea Secret Server, BeyondTrust Password Safe
IAM السحابي: AWS IAM, IAM Identity Center, Azure RBAC, GCP IAM
البرمجة: PowerShell, Python, Bash
الدلائل: Active Directory, LDAP, Azure AD
الأدوات: Wireshark, Postman, Git, Docker, Terraform
```

### الخبرة

لكل دور، استخدم الصيغة: إجراء + تقنية + نتيجة.

```
مهندس IAM | الشركة X | 2023 - الحاضر
- تكامل 15 تطبيق SaaS مع Entra ID عبر SAML و OIDC، خفض تذاكر دعم SSO بنسبة 60%.
- بناء خط أنابيب تزويد SCIM بين Workday و Entra ID، أتمتة دورة حياة المستخدم لـ 5,000 موظف.
- تكوين سياسات Conditional Access تفرض MFA لكل وصول خارجي، خفض حوادث اختراق الحساب بنسبة 80%.
- استكشاف أخطاء تعيين تأكيد SAML باستخدام أدوات مطوري المتصفح و SAML-tracer، حل أكثر من 20 مشكلة تكامل.
```

### المشاريع

إذا كنت تفتقر إلى الخبرة المهنية، المشاريع هي دليلك. اذكرها مثل الخبرة العملية.

```
المعمل المنزلي: IAM للمؤسسات مع Keycloak | 2024
- نشر Keycloak كمزوّد هوية مع اتحاد LDAP إلى Active Directory.
- تكوين عملاء SAML و OIDC لثلاثة تطبيقات، إثبات SSO متعدد البروتوكولات.
- بناء عميل تزويد SCIM بلغة Python لأتمتة إنشاء المستخدمين وإلغاء التزويد.
- توثيق المشروع بأكمله على GitHub مع مخططات بنية معمارية وأدلة خطوة بخطوة.
```

### التعليم والشهادات

اذكر الدرجات العلمية والشهادات مع التواريخ. ضع الشهادات قيد التقدم كـ "قيد التقدم (متوقع 2026)."

## أفكار مشاريع المعرض

مشروع المعرض يثبت مهارات لا تستطيع السيرة الذاتية إثباتها. ابنِ شيئًا يحل مشكلة حقيقية ووثّقه علنًا.

### المشروع 1: مركز SSO متعدد البروتوكولات

ابنِ نطاق Keycloak يعمل كمزوّد هوية لتطبيقات متعددة باستخدام بروتوكولات مختلفة (SAML, OIDC, LDAP). وثّق البنية المعمارية، وخطوات التكوين، والتحديات التي حللتها.

### المشروع 2: أتمتة تزويد SCIM

ابنِ سكربت Python يقرأ بيانات المستخدمين من CSV ويزوّد المستخدمين إلى تطبيق متوافق مع SCIM. تعامل مع عضوية المجموعات، وإلغاء التزويد، وحالات الخطأ. انشر الكود على GitHub مع README يشرح قرارات التصميم.

### المشروع 3: تحليل تسجيلات جلسات PAM

إذا كان لديك وصول إلى تجربة PAM (CyberArk, Delinea)، سجّل جلسة مميزة وحللها. وثّق ما يلتقطه التسجيل، وكيفية البحث فيه، وما هي مؤشرات الاختراق في تسجيل الجلسة.

### المشروع 4: محاكاة الاستجابة للحوادث

حاكي اختراق حساب خدمة في بيئة معمل. وثّق خطوات الكشف، والاحتواء، والاستئصال، والتعافي. انشر الجدول الزمني للحادث والدروس المستفادة.

### المشروع 5: تعدين أقل الامتيازات في IAM السحابي

استخدم AWS Access Advisor و IAM Access Analyzer لتحديد أدوار IAM ذات الامتيازات المفرطة في حساب اختبار. وثّق النتائج وخطوات المعالجة. انشر المنهجية كمنشور مدونة أو مستودع GitHub.

## عرض GitHub

ملفك الشخصي على GitHub هو معرضك العام. اجمه قابلًا للعرض.

### هيكل المستودع

كل مشروع يجب أن يحتوي على:

- **README.md**: ماذا يفعل المشروع، لماذا يوجد، كيفية إعداده، ماذا يثبت.
- **مخطط البنية المعمارية**: مخطط Draw.io أو Mermaid يوضح المكونات والتدفقات.
- **ملفات التكوين**: التكوين الفعلي المستخدم، مع إخفاء الأسرار.
- **السكربتات**: أي سكربتات أتمتة، مع تعليقات تشرح ماذا تفعل.
- **التوثيق**: مجلد docs/ مع شروحات مفصلة لقرارات التصميم.

### ما يجب تجنبه

- **لا README**: مستودع بدون README غير مرئي. اكتب README دائمًا.
- **أسرار مضمّنة**: لا تلتزم أبدًا بكلمات المرور أو مفاتيح API أو الرموز. استخدم متغيرات البيئة أو ملف .env.
- **لا التزامات**: مستودع بالتزام واحد يبدو مهجورًا. التزم regularly برسائل ذات معنى.
- **مستودعات مفروزة بدون شرح**: إذا فرعت مستودعًا، اشرح ما غيّرته ولماذا.

## ما تعلمه هذه الصفحة

- مديرو التوظيف يبحثون عن إشارات محددة: تقنيات، بروتوكولات، أرقام حجم، نتائج مشاريع، وأدلة استكشاف أخطاء.
- هيكل السيرة الذاتية مهم: ملخص، مهارات، خبرة، مشاريع، تعليم. كل قسم له غرض محدد.
- مشاريع المعرض تثبت مهارات لا تستطيع السيرة الذاتية إثباتها: ابنِ شيئًا حقيقيًا ووثّقه علنًا.
- GitHub هو معرضك العام: كل مستودع يحتاج README ومخطط بنية معمارية وتوثيق.
- LinkedIn هو المكان الذي يجدك فيه مسؤولو التوظيف: حسّن عنوانك وقسم نبذة ومهاراتك لأدوار IAM.
