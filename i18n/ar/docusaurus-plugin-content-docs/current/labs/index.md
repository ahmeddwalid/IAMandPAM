# المختبرات والمشاريع التطبيقية (Hands-On Labs)

تكتسب المعرفة النظرية مصداقيتها عندما تثبتها عملياً في بيئة تطبيقية حقيقية. صُممت هذه المشاريع العشرة لتعمل بالكامل على حاسوبك الشخصي باستخدام أدوات مجانية ومفتوحة المصدر: VirtualBox، ونسخة Windows Server التقييمية، و Keycloak كمزود هوية ذاتي الاستضافة، وحساب AWS المجاني، ومنصة HashiCorp Vault، وأداة Teleport على Docker.

يوضح كل مختبر بدقة ما يثبته، والوقت المقدر لإنجازه، والخطوات التفصيلية مع اختبارات التحقق من صحة التنفيذ.

## تكلفة الأدوات البرمجية المستخدمة

كافة الأدوات المستخدمة مجانية بالكامل أو تتوفر على باقة استخدام مجانية كافية للمختبر:
- **VirtualBox**: برنامج إدارة الأنظمة الافتراضية المجاني ومفتوح المصدر (GPL).
- **Windows Server Evaluation**: نسخة تقييمية رسمية مجانية من مايكروسوفت صالحة لـ 180 يوماً.
- **Keycloak**: مزود الهوية المرجعي مفتوح المصدر (Apache 2.0).
- **AWS Free Tier**: باقة الاستخدام السحابي المجانية لمدة 12 شهراً.
- **HashiCorp Vault & Teleport**: الحزم المجانية مفتوحة المصدر التي تعمل محلياً عبر حاويات Docker.

العتاد الموصى به لتشغيل البيئة كاملة: حاسوب محمول بذاكرة عشوائية (RAM) لا تقل عن 16 جيجابايت، ومساحة تخزين حرة 80 جيجابايت، ومعالج يدعم ميزات المحاكاة الافتراضية (VT-x / AMD-V).
