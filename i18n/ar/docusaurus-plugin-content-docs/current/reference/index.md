# المراجع والملاحق الفنية (Reference)

الطبقة المرجعية المركزة للموقع: التعريفات الاصطلاحية الدقيقة، صيغ الأوامر، والروابط التوثيقية المعتمدة.

---

## أقسام المراجع

- **[معجم المصطلحات الأمني (Glossary)](glossary.md)**: كافة الاختصارات والمفاهيم المستخدمة عبر المرجع، مع روابط مباشرة لصفحة الشرح المفصل.
- **[الجداول المرجعية المركزة (Cheat Sheets)](cheat-sheets.md)**: ملخصات سريعة لعناصر SAML و OAuth/OIDC، وفلاتر LDAP المتقدمة، وأهم أوامر PowerShell لإدارة الهويات.
- **[مصفوفة الامتثال للوائح والمعايير](compliance-mapping.md)**: ربط متطلبات SOX 404 و PCI DSS 4.0 و ISO 27001:2022 و NIST CSF 2.0 بقدرات IAM الأساسية.
- **[دليل التدقيق الشامل لبرامج IAM](iam-program-audit.md)**: خطة تدقيق عملية خطوة بخطوة للتحقق من سلامة البيئة التشغيلية للهويات.
- **[معايير تعريب مصطلحات الهوية](06-arabic-terminology-standard.md)**: المعجم القياسي لتعريب مفاهيم الهوية والوصول المعتمد في هذا المرجع المتوافق مع الأطر التنظيمية الإقليمية.
- **[روابط التوثيق والمعايير الرسمية](external-links.md)**: مراجع RFC الرسمية، وتوثيقات الموردين الرسمية، وروابط الهيئات القياسية المعتمدة.
